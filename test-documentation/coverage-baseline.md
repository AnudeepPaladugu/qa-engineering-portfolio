# Coverage baseline

Denominators are the agreed portfolio scope, not all behavior of the public website.

- Functional requirement design coverage: 18/18 requirements have at least one case = 100% of the defined functional baseline. This is design traceability, not execution coverage.
- Scenario design coverage: 32/32 scenarios have a detailed case = 100% of defined scenarios.
- Planned automation coverage: 20/32 cases = 62.5%; implemented and executed automation coverage is 0/32 at this design stage.
- Planned smoke scope: 7/20 UI cases = 35% (TC-UI-001, 004, 005, 007, 011, 014, 016).
- Planned regression scope: 20/20 UI cases = 100% of the selected UI automation scope; manual/API charters are not included in that percentage.

Counts must be recalculated if case inventory or groups change. Non-functional audit targets are tracked separately from the 18 functional requirements.
