# Execution record template

- Run ID / timestamp / tester:
- Git commit / environment / application build / browser / platform:
- Case ID / requirement / scenario:
- Expected result: copy the exact relevant step expectations.
- Actual result: record observed text, URL, values and behavior.
- Status: PASS / FAIL / BLOCKED / SKIPPED / NOT EXECUTED.
- Defect ID: required for a failed comparison; triage classification required.
- Evidence location / stack trace / logs:
- Duration:
- Cleanup outcome:

BLOCKED means a documented prerequisite prevented execution. SKIPPED is a deliberate omission or runner skip. NOT EXECUTED means no attempt. None of these is PASS.
