# Project Overview

## What is this project?

This is an end-to-end QA portfolio project built around a public e-commerce application.

The goal is to demonstrate how a QA Engineer approaches a product from initial understanding through testing, defect reporting, automation and final quality assessment.

## Application

**Automation Exercise**, a public e-commerce demo application.

## My QA workflow

1. Inspected the application and mapped its behaviour.
2. Identified functional and non-functional requirements.
3. Designed test scenarios and detailed test cases.
4. Executed manual functional, negative, boundary and exploratory tests.
5. Documented defects with reproducible evidence.
6. Selected stable, repeatable regression scenarios for automation.
7. Implemented UI automation using Java, Selenium and TestNG.
8. Created API checks using Postman/Newman.
9. Collected screenshots, logs and execution results.
10. Reviewed the final evidence and made a QA recommendation.

## What this demonstrates

This project demonstrates both **QA execution skills** and **QA engineering skills**. It is not only a collection of Selenium scripts.
