## Coverage by test type

### Functional testing
Verifies that features behave according to their expected functionality.

### Negative testing
Uses invalid or unexpected inputs to check whether the application protects itself from incorrect behaviour.

### Boundary testing
Checks values at or around allowed limits.

### Exploratory testing
Uses investigation and observation to find behaviour that scripted tests may not cover.

### UI automation
Automates repeatable regression checks so they can be executed consistently.

### API testing
Verifies API behaviour independently from the browser UI.
