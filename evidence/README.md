# Test Evidence Guide

This folder contains selected, committed evidence from project execution.

## Evidence groups

| Folder | What it demonstrates |
|---|---|
| [Latest Regression](latest-regression/) | Most recent UI regression result |
| [Postman](postman/) | API collection execution evidence |
| [Exploratory](exploratory/) | Exploratory observations and screenshots |
| [Smoke](smoke/) | Smoke-suite evidence |
| [Initial Regression](initial-regression/) | Earlier baseline execution |
| [Framework Audit](framework-audit/) | Evidence that intentional assertion failures are captured correctly |
| [Discovery](discovery/) | Evidence collected while inspecting application behavior |

## Important

Evidence is supporting proof, not a replacement for the written test documentation.

The latest execution and QA conclusion are summarized in the root [README](../README.md) and [project results](../project-overview/06-results-and-conclusion.md).

Historical runs are retained when they help demonstrate the testing journey. Generated runtime output remains under artifacts and is intentionally not treated as curated portfolio evidence.
